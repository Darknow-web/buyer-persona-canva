# Buyer persona · Katherine Ríos Vásquez (ANDIBITE)

Buyer persona interactivo y animado, en un solo archivo HTML sin dependencias de build.

- `index.html`: página completa (tema claro/oscuro, línea de tiempo del día, ranking de decisión animado, test de lonchera con simulador de precio, carrusel de frases, señales rojas y bloque de encaje con ANDIBITE).

Abrir `index.html` en cualquier navegador. Las fuentes se cargan desde Google Fonts; sin conexión se usan las fuentes del sistema.

Fuente de los datos: entrevistas y focus group. Nombre y edad exacta son representativos.
