# Buyer persona · Katherine Ríos Vásquez (ANDIBITE)

Buyer persona interactivo y animado en un solo archivo HTML, sin build ni dependencias.

## Archivos
- `index.html`: la página completa. Tema claro/oscuro, línea de tiempo del día, ranking de decisión animado, test de lonchera con simulador de precio, carrusel de frases, señales rojas, bloque de encaje con ANDIBITE y botón para imprimir o guardar en PDF.
- `katherine.png` (opcional): si colocas una imagen con este nombre junto a `index.html`, la página la usa como retrato en lugar de la ilustración. Formato recomendado: 5:4 (por ejemplo 1000 × 800 px).

## Cómo verla
Abre `index.html` en cualquier navegador. Las fuentes vienen de Google Fonts; sin conexión se usan las del sistema.

## Cómo publicarla
- **GitHub Pages**: en el repositorio, Settings → Pages → Source: "Deploy from a branch", elige la rama y la carpeta raíz. La página queda en `https://<usuario>.github.io/<repo>/`.
- **Google AI Studio (Build)**: crea una app nueva, pega el contenido de `index.html` como `index.html` del proyecto (o importa el repositorio) y usa "Deploy". Como es HTML puro, no necesita ningún cambio.
- **Cualquier hosting estático** (Netlify, Vercel, Cloudflare Pages): sube la carpeta tal cual.

## Datos
Perfil compuesto a partir de entrevistas y focus group. Nombre y edad exacta son representativos; comportamientos, montos y frases vienen de la data.
